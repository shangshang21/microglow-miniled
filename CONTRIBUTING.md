# 一起补充案例 / Contributing

欢迎提供面板标签型号、驱动板号、连接方式、固件 SHA-256、软件复现步骤，以及你亲眼观察到的效果。请区分“请求成功”“读回变化”和“画面真的变化”。照片请确认有权公开，并遮住序列号和个人信息。

Please include panel and PCB models, connection type, firmware SHA-256, software reproduction steps and what you actually observed. Distinguish successful requests, changed readback and optical changes. Only upload photos you may publish, with serial numbers and personal details removed.

**不要上传完整固件、整片备份、固件 bank 导出、厂商工具或商业数据库。请勿把本案例的地址直接用于未知固件。**

**Do not upload full firmware, device dumps, firmware-bank exports, vendor tools or commercial databases. Do not apply case-specific offsets to unknown firmware.**

代码贡献采用本仓库的 GPL-3.0-only。提交时说明修改理由与实际检查；没有实物验证的兼容性请标为未验证。

Code contributions use GPL-3.0-only. Explain the change and checks performed; mark compatibility without physical testing as unverified.
